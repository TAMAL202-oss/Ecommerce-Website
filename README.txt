TM STORE — FRONT-END E-COMMERCE STARTER

HOW TO RUN
1. Extract the ZIP file.
2. Keep index.html, style.css, script.js, and the img folder together.
3. Double-click index.html to open it in your browser, or use VS Code with the Live Server extension.

FILES
- index.html: page structure and product content
- style.css: responsive layout and styling
- script.js: product filters, demo cart, mobile navigation, newsletter interaction
- img/logo.png: your TM shopping-cart logo

NOTES
- Product photos and Google Fonts load from the internet.
- This is a front-end demo. Cart state is not saved after refresh and checkout does not process payments.
- To accept real orders, add a backend/database and integrate a payment provider. Replace demo product details and prices with your real catalogue.
